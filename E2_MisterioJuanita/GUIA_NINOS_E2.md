# El misterio de Juanita

## Las cuatro memorias

**Equipo:** ____________________  **Fecha:** ____________________

Juanita es un alma buena que está en el cielo. Una presencia amable intenta
hablar desde el Cardputer, pero los susurros de la casa han escondido cuatro
de sus memorias. Recuperadlas para descubrir su mensaje.

## El equipo de investigadores

- **Lector/a:** lee en voz alta las pistas de la pantalla.
- **Cronista:** apunta cada memoria encontrada.
- **Explorador/a:** resuelve las pistas y busca las tarjetas.
- **Guardián/a:** lleva las tarjetas al lector RFID.
- **Operador/a:** utiliza el teclado al final.

Podéis cambiar de función después de cada memoria.

## Reglas de la investigación

1. El Cardputer y sus cables se quedan en el salón.
2. No toquéis los pines ni desconectéis ningún cable.
3. No mantengáis pulsado `G0`: borraría la partida.
4. Leed cada pista completa antes de salir corriendo.
5. No probéis tarjetas al azar.
6. No entréis en lugares peligrosos ni toquéis líquidos, enchufes, medicinas
   o productos de limpieza.

## Cómo recuperar una memoria

1. Pulsad `ENTER` para escuchar el primer susurro.
2. Resolved el acertijo de la pantalla para descubrir el dormitorio.
3. Buscad allí la tarjeta escondida.
4. Llevad la tarjeta encontrada al salón.
5. Acercadla plana al RFID2 durante un segundo.
6. Si es correcta, apuntad inmediatamente su color y su número.

## El mensaje final del HEX

Cuando tengáis las cuatro memorias, el HEX repetirá cuatro colores. Esos
colores indican el orden correcto de los números.

Observad dos repeticiones completas:

| Destello | Color del HEX | Número de esa memoria |
|---:|---|---:|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |

**Código final:** `[ _ ][ _ ][ _ ][ _ ]`

- Escribid las cuatro cifras con el teclado.
- `DEL` borra la última.
- `ENTER` comprueba la respuesta.

## Informe de los investigadores

Cuando termine la partida, contestad juntos:

1. ¿Qué pista os pareció más difícil?
2. ¿Por qué era importante apuntar cada memoria?
3. ¿Qué eran las entradas del programa?
4. ¿Qué eran sus salidas?
5. ¿Qué nuevo misterio añadiríais a la casa?

### Diccionario secreto

- **UID:** número que identifica una tarjeta RFID.
- **Entrada:** información que recibe el programa, como teclado o RFID.
- **Salida:** información que produce, como pantalla, sonido o luces.
- **Escena:** etapa actual del misterio.
- **Sustitución:** cambiar un símbolo por otro siguiendo una regla.
