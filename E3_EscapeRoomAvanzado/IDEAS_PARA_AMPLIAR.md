# Ideas para ampliar esta mecánica

- Cambiar `ORDEN_COLORES` en cada partida y hacer que una prueba anterior
  descubra la nueva relación color → posición.
- Utilizar cruz, rombo o línea en partidas posteriores sin cambiar la
  tabla codificadora que ya conocen los jugadores.
- Añadir una cuarta tarjeta señuelo que el lector reconozca, pero que no tenga
  hueco en el tablero.
- Después de acertar el número, desbloquear un nivel adicional de escritura
  RFID. No forma parte de esta versión para que el primer ensayo sea claro.
- Emitir una segunda clave con sonidos en código Morse.
- Usar la IMU del Cardputer para que una pista anterior se resuelva inclinando
  la placa en una secuencia.
- Guardar pistas y orden de colores en la microSD para diseñar partidas sin
  recompilar.

El RFID2 solo puede leer una tarjeta cada vez y no detecta dónde está colocada
sobre el papel. El programa comprueba el orden mediante el número final que
introducen los jugadores.
