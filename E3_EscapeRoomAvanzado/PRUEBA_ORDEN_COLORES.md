# Prueba anterior — El orden de las tres luces

Antes de buscar las tarjetas aparecieron tres luces, una detrás de otra.
Reconstruid su orden con estas pistas:

```text
┌────────────────────────────────────────────────────┐
│  • El color de las HOJAS apareció antes que        │
│    el color del FUEGO.                             │
│                                                    │
│  • El color del CIELO fue el último.               │
│                                                    │
│  • El color del FUEGO no fue el primero.           │
└────────────────────────────────────────────────────┘

Posición 1 → color __________________

Posición 2 → color __________________

Posición 3 → color __________________
```

Guardad el resultado. Más adelante descubriréis para qué sirve.
